1) Выгружаются последние 50 рейтинговых(!) попыток
2) Во все темы этой задачи добавляется стоимость задачи, если она есть
3) Считается средняя стоимость задач в каждой теме
4) Считается отношение средней стоимости задач к рейтингу пользователя - Условные шансы($Chance$)
5) Для последних ~100 задач с раундов считается Условная стоимость($NewCost$) по формуле:$$NewCost = Chance * Cost$$
6) Если разница рейтинга участника с Условной стоимостью не превышает некой константы(пока это 100), то задача считается Рекомендуемой.
